# Alemán al oído

Repaso hablado del banco de frases «Alemán desde cero»: frases completas de alta frecuencia para charlas
informales cara a cara, con el texto sincronizado y uso sin datos.

Método: el vocabulario, la gramática y la pronunciación se aprenden dentro de frases completas, con
repetición constante (escuchar muchas veces, repetir en voz alta y decirlas de memoria varios días por semana).
